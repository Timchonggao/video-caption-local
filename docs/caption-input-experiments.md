# 后续能力：视觉输入扩展实验

当前先完成 sample_01 简单 v1 基线。本页方向尚未作为当前运行配置启用。

固定任务、模型、背景、输出预算和人工评价维度，每次只改变一个输入因素。按全部六路独立任务评价，不把多路联合输入混入单相机结果。

| 方向 | 假设与对照 | 成本及采用标准 |
| --- | --- | --- |
| 单相机时间网格 | 独立时间帧对比带时间标题网格；布局、字体、编码版本进入输入指纹 | 记录实际输入 token/尺寸，确认动作顺序识别改善且小物体错误未增加 |
| 概览与细节帧 | 均匀抽帧对比首末合法帧及关键操作附近高清帧；关键点选择方式需固定，不使用尚未接入的状态通道 | 比较接触、状态变化错误及遗漏，同时记录图片数、内存、token 和耗时 |
| 显式分辨率配置 | 同一时间帧对比多档像素预算；不增加模型路由调用 | 按小物体、遮挡、操作复杂度分组，选择质量与成本合适的配置 |
| 人工确认 few-shot | 相同指令下有/无独立示例；示例来源和版本进入指纹，不来自评估片段 | 检查示例内容泄漏、语言复述、对象幻觉和实际操作覆盖 |

人工评价至少包括物体、操作、空间、顺序、状态结果、目的因果错误及整体遗漏。预先约定采用标准，不仅凭生成文本流畅程度。视频展示压缩副本与推理原始输入仍分开。
