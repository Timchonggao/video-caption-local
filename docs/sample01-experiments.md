## 固定任务域

sample_01 全部 24 个原始 sub_segments_info 子片段 × camera0–camera5 = 144 个稳定 task_id。不按 is_success 或时间／帧有效性过滤。解码或准备失败单独记录，不把任务从清单中移除，不改原始边界。

## 新 v1：纯视觉基线

配置 configs/sample01_v1.json；Prompt prompts/sample01_baseline_v1.txt。每个原始片段、每路相机独立生成 1–2 句英文文本。不提供 sample caption、fine_label 或上一段 caption；不使用内部窗口，不做文字汇总，不生成动作结构化清单。

每片段均匀请求 12 帧（不是 12 fps）：对 [start,end) 生成 12 个等距目标时间点，选择区间内最近的真实 PTS，记录偏差与重复帧。如果没有可解码画面或偏差超过 1 秒，记录准备失败。长片段也只有 12 个目标点，可能遗漏短暂操作；这正是随后采样密度实验要检查的问题，不能视为最终采样方案。

始终读取 CFS 高清原件；处理器每帧像素预算 512000，模型实际输入尺寸保存在证据中，因此不等同于原尺寸逐像素输入。输出上限 256 token；截断记录为失败，不悄悄接受不完整文本。CPU 使用 4 线程，单任务串行。

## 运行入口（从仓库根目录执行）

先准备一个任务，不加载 GPU 模型、不调用 API：

```bash
env/bin/python project/scripts/run_sample01_v1.py
```

准备检查通过后，可先生成一个任务：

```bash
env/bin/python project/scripts/run_sample01_v1.py --apply
```

覆盖全部 144 个任务、使用相同配置续跑：

```bash
env/bin/python project/scripts/run_sample01_v1.py --limit 144 --max-calls 144 --apply
```
