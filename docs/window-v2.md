# 后续能力：原始子片段内的窗口与汇总

本页保存探索方向，不定义新一轮实验的 v2；当前只运行 sample01-experiments.md 中的简单 v1。启用窗口、采样或历史时分别建立新实验，避免同时改变多个因素。

正式任务域仍为 138 个原始子片段 × 6 路相机（828 个 task_id）。不按 is_success 或时间／帧有效性筛选，不修改原始标注、源视频或看板播放边界。

## 输入和历史

每个原始子片段从自身起点按半开区间划分不超过 5 秒的内部窗口，尾窗口不补足。12 fps 生成目标时间点，从 CFS 高清源视频选取最近的合法 PTS；重复帧去重并保存实际时间与偏差，缺少可解码帧时记录失败，不伪造输入。

每个窗口都收到样本原始 caption 与整个原始子片段 fine_label，作为可错的标注背景而非视觉证据。只描述当前窗口可见操作，不补齐标签中的步骤。后续窗口只引用同一原始任务内前一窗口的活动结果版本；跨子片段和跨相机重置历史。历史失败时后续窗口等待，整个任务不产生冒充完整结果的摘要。

Prompt 原文见 prompts/modules/；实际输入以运行配置中的文本快照为准，不维护合并副本。四个 v1 模块继续定义观察与 JSON 输出，05_window_v2 明确窗口边界。06_summary_v2 用于多窗口文字汇总，不添加新的视觉证据。单窗口直接采用其结果，不额外调用汇总模型。

## 保存与续跑

runs/<run_id>/ 保持正式 config、tasks、results、metrics、run.log、active、versions。内部 windows/<parent_task_id>/ 保存独立窗口 manifest、输入、抽帧、张量、活动结果及前驱版本。内部 task_id 是计算身份，window_id 是公开追溯身份，不能作为正式评价目标。正式结果保留窗口追溯并绑定自己的 result_id。

同一 run 的代码／Prompt／采样／模型配置固定；改变配置必须使用新 run ID。成功任务续跑不新增调用；未完成任务重用相同输入的窗口成功结果。显式 --rerun 重跑选中任务的全部窗口和汇总。--max-calls 统计视觉窗口及文字汇总的模型调用总数；--limit 按正式任务计数。调用预算不足时保留窗口结果，等待下一次续跑。

## 小规模命令

从仓库根目录执行，默认 dry-run；--apply 才生成。与 v1 相同的 512000 每帧像素预算，不代表模型看到原尺寸的全部像素；高清原件不变。

```bash
env/bin/python project/scripts/caption.py \
  --run NEW_RUN_ID --prompt-id window-v2 \
  --window-seconds 5 --sampling-fps 12 \
  --max-pixels 512000 --max-new-tokens 1600 \
  --max-request-bytes 1073741824 \
  --task-id sample_01_seg01_sub01__camera0 \
  --max-calls 3
```

真实 60 帧输入的 CPU 张量约 676 MiB，超过旧 512 MiB 请求预算，故 v2 小试显式使用 1 GiB 请求阈值。CPU 请求阈值不是 GPU 显存上限；模型生成保存每张卡的峰值 allocated/reserved bytes。没有自动降帧率、降低图像预算或 OOM 重试。

后续产生窗口实验后，在本地网页选择对应版本和相机，显示最终 caption；“窗口结果与追溯”可展开各窗口描述、时间和版本。不会自动上传云端或调用豆包／Gemini。质量需看完整高清视频人工评价；JSON 有效不等于动作准确。

## 显式 JSON 语法规范化

`normalize_window_json.py --run RUN_ID` 默认只列出候选，`--apply` 才写入新窗口结果版本。仅接受一个完整可解析 JSON 对象之后恰好一个多余引号；再做完整 schema 校验。拒绝截断、多对象、缺字段及其他尾部文本，不补写内容。原始失败版本与 raw_model_output 保留，新结果标记 valid_normalized，记录原 result_id、规范化脚本哈希和零模型调用。

该工具取得父运行和窗口运行锁，不能与生成同时执行。处理后再用相同配置续跑，重用窗口结果并生成正式片段汇总；不会自动重跑全部模型。


## 操作证据约束改进版（待试跑）

改进窗口模块：`prompts/modules/05_window_v2_refined.txt`；改进汇总模块：`prompts/modules/06_summary_v2_refined.txt`。这些模块保留为后续选择，不自动进入当前基线；旧试跑快照已删除。

改进点：区分衣架／衣物及其附着关系；区分移动、接触、受支撑和释放；每个窗口独立观察，不把历史中的暂停、调整或放置复制到当前窗口；允许真实重复动作简短重复；删除目的推测及无关场景介绍；汇总保留不确定性，不把重复文字当作重复事件次数。JSON schema 不变。

旧改进版专用试跑入口已删除。后续实验可通过通用入口显式选择窗口与汇总模块，仍须先核对配置再生成。

通用入口新增 `--window-prompt FILE` 与 `--summary-prompt FILE`，仅在窗口模式可用；内容保存进运行配置。改变 Prompt 或代码后使用新运行编号，既有配置不可覆盖。

降低输出冗余可能减少实际生成 token，但 `max_new_tokens` 只是上限，降低上限不是可靠的加速方法，可能截断 JSON。采样率和图像预算不在本次 Prompt 修改中自动降低。
