# 可组合的 caption Prompt 模块

本目录保存可组合的提示词片段。本目录保留后续升级模块。当前实验使用 ../sample01_baseline_v1.txt，不使用这些模块。通用 caption.py 未指定 --prompt 时按下面顺序组装；运行配置保存实际使用的文本与哈希，不再维护合并阅读副本。

## 模块组装顺序

| 顺序 | 文件 | 职责 |
| --- | --- | --- |
| 1 | `01_observation_scope_v1.txt` | 描述目标与观察维度 |
| 2 | `02_context_boundary_v1.txt` | 标注、历史与视觉证据边界 |
| 3 | `03_continuity_v1.txt` | 连续性、缺失历史与时间关系 |
| 4 | `04_output_v1.txt` | 精简 JSON 输出与表达要求 |

按上述顺序组装指令，实际背景、历史和帧信息另以固定数据区提供。模块 4 使用新输出契约，校验器兼容新旧格式；输入、结果和运行规则见 `project/docs/caption-engineering.md`。没有新增自动视觉核查模块。

## 第一部分：描述目标与观察维度

文件：`01_observation_scope_v1.txt`。

使用英文编写，便于后续与现有英文 caption Prompt 组合。内容覆盖九个观察维度：

1. 对象与角色：物体、工具、材料、容器、支撑面、必要属性与数量。
2. 手部或夹爪操作与协作：固定、交接、换手、重新抓握。
3. 接触与操作方式：接触部位、具体动作、方向与重复方式。
4. 空间关系与转移：来源、去向、支撑、容纳、连接与插入关系。
5. 动作顺序与推进：准备、执行、调整、清理与归位。
6. 可见状态变化与结果：区分执行动作与达成结果。
7. 尝试、异常与恢复：描述具体事件，重复动作不自动判为失败。
8. 工具作用与流程关联：描述实际作用，不凭常识补写意图或因果。
9. 可见范围与不确定性：遮挡、画面外事件、身份不明及缺失起止。

这些维度用于指导观察，不要求逐项回答，也不规定输出字段。优先保留理解操作所需的细节，不把 caption 写成九项问答。

## 组合边界

本模块不规定输出语言、句数、JSON 结构、时间坐标、上下文注入方式或多视角融合格式。后续可分别增加对应模块，再组装为完整 Prompt。

原始标注、上一段结果及其他相机信息不能作为当前视角直接观察到的事实。后续上下文模块应保留这一证据边界；多视角融合应明确其独立输入与证据来源。

运行实验时建议保存最终组装的完整 Prompt 和模块版本，以便复现；模块能力不自动进入当前基线；每次升级应显式选择并用新运行编号。

## 设计来源

参考 EgoTools 论文的感知与定位、操作过程、空间推理、功能与因果四类能力，以及本地 `previous_work/egotools/src/egotools/data/benchmark/assign_benchmark_research_tracks.py` 中的细分类。

代码细分类是研究整理建议，并非论文最终标签的自动重建。本模块是面向当前多相机操作视频的设计，不是 EgoTools 官方 caption Prompt 的复刻。工具选择理由、真实意图、替代工具适用性和未来规划不作为纯视觉 caption 的必填内容。

论文：https://arxiv.org/html/2609.39378v1
